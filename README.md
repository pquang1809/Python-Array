# Python Array Practice

A collection of beginner-friendly Python exercises focused on arrays (lists), loops, conditional statements, and basic problem-solving.

## Exercises

### 1. Find the Maximum and Count Occurrences
- Find the largest number in a list.
- Count how many times the largest number appears.
- **Concepts:** Lists, loops, conditional statements.

### 2. Count Occurrences of a Value
- Count how many elements in a list are equal to a given value.
- **Concepts:** Lists, user input, `split()`, `map()`, loops.

### 3. Find the Maximum in a 2D List
- Find the largest number in a two-dimensional list.
- Count how many times the largest number appears.
- **Concepts:** Nested lists, nested loops, conditional statements.
